# Week 8 – Student Performance Data Analysis

## 📌 Project Overview
This project focuses on exploring and understanding student performance data using Python. It analyzes students' academic scores and demographic information.

## 🎯 Objectives
- Load and explore the student performance dataset.
- Understand the structure of the dataset.
- Analyze students' math, reading, and writing scores.
- Explore demographic information.
- Identify unique values in categorical columns.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📂 Dataset
**Dataset Name:** StudentsPerformance_preprocessed

The dataset contains:
- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

## 🔍 Data Exploration
The following Pandas functions are used:

- `df.head()` – Displays the first 5 rows.
- `df.tail()` – Displays the last 5 rows.
- `df.info()` – Shows dataset information.
- `df.describe()` – Displays statistical summaries.
- `df.columns` – Displays column names.
- `df.shape` – Shows the number of rows and columns.
- `df.unique()` – Identifies unique values in selected columns.

## 📊 Analysis
The project explores two main categories:

**1. Academic Performance**
- Math Score
- Reading Score
- Writing Score

**2. Demographic Information**
- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course

## ✅ Conclusion
This project provides a basic understanding of student performance data through data exploration using Python and Pandas. It helps identify dataset characteristics, academic score columns, and demographic categories.
